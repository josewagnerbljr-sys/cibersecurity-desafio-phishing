# Texto de Entrega

Projeto: Desafio de Phishing — Simulação Educacional Segura

Este projeto apresenta uma página de login simulada desenvolvida para estudar phishing e engenharia social em ambiente local e controlado.

A implementação utiliza HTML, CSS e JavaScript e reproduz o fluxo visual de uma tela de autenticação, sem representar um serviço real.

Como medida de segurança, a solução não captura, armazena ou transmite senhas. O envio do formulário é interceptado localmente e o usuário recebe uma mensagem educativa sobre o risco de inserir credenciais em páginas suspeitas.

O repositório contém:

- README.md com a documentação do projeto;
- página HTML da simulação;
- folha de estilos CSS;
- JavaScript do laboratório;
- documentação de execução;
- relatório técnico;
- pasta destinada às evidências em imagem.

Ferramentas e conceitos estudados: Kali Linux, SEToolkit, phishing, engenharia social, autenticação, análise defensiva e GitHub.

O projeto foi estruturado dessa forma para manter o experimento acadêmico sem utilizar credenciais reais ou coletar dados de terceiros.
